PresetTint

A SMALL PALETTE EDIT

プリセットの色を、\n必要なところだけ。

既存の OpenSCAD Customizer JSON からプリセットとキーを選び、色の値だけを編集。RGB の要素数と、選んでいないデータを保持します。

OFFLINE · ローカル処理

モデルは読み込み・実行しません。既存の値の形式を使い、モデル側の選択肢や数値範囲は検証しません。

01プリセットを選ぶ

UTF-8・最大 4 MiB。fileFormatVersion は文字列の "1"、各パラメーター値も文字列です。

プリセットを切り替えると、未保存の編集をクリアします。

編集するキーを、明示的に選択

0

色に似た値の形式を表示します。位置などのベクトルも似た形式になるため、キーの意味を確認してください。最大 32 キー。

形式と制限

6 桁 #RRGGBB、または 0–1 の RGB / RGBA ベクトル文字列に対応。短縮・名前・8 桁の hex などは編集対象外です。

元の要素数を保持します。RGB と hex は不透明のまま、既存の RGBA だけがアルファを編集できます。

最大 200 プリセット・10,000 パラメーター・深さ 24。重複キーや NFC 正規化で重なるキー、文字列以外の値はブロックします。

選んだ値の文字列トークン以外は、そのまま保持します。元ファイルを残し、コピーを書き出します。

OpenSCAD は通常、モデルと同じ名前の JSON を隣に探します。コピーの配置・名前を、対応するモデルに合わせてください。

小さな色変更に、確かな境界を。

プリセットとキーは自動選択しません。モデルの制約やキーの意味は、対応するモデルで確かめてください。

変更の記録も残せます

選択キー、変更前後の文字列、RGBA 数値と量子化差、入力・出力の SHA-256 をレシートに保存します。
